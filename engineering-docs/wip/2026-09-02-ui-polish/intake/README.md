# UI Polish Intake Queue

This directory receives tasks, design notes, UI defect reports, and styling requests for `ui-polish`.

Per `WORKFLOW.md`:
- Each item is named `YYYY-MM-DD-<sender-mnemonic>-<slug>.md`.
- Items are dispositioned by acknowledging or forwarding to `project-management`.
- Dispositions are recorded in `../intake-dispositions.md`.
